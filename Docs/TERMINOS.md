# Borrador de términos y condiciones

**Estado:** Borrador pendiente de revisión legal.

## 1. Servicio

TapMon: Mi Compi Virtual es una aplicación de entretenimiento para dispositivos Android. El uso de la aplicación implica aceptar estas condiciones cuando se publiquen junto con una versión final.

## 2. Uso permitido

La persona usuaria debe utilizar la aplicación de forma lícita y no intentar alterar su funcionamiento, sus datos locales o los servicios de terceros integrados.

## 3. Progreso y datos locales

El progreso del juego se almacena localmente mediante PlayerPrefs. La desinstalación, limpieza de datos o fallo del dispositivo puede eliminarlo.

## 4. Publicidad

Las versiones que integren AdMob podrán mostrar banners y anuncios recompensados. Durante el desarrollo se utilizarán exclusivamente IDs de prueba. La versión de producción deberá usar una configuración aprobada y cumplir las políticas de Google Play y del proveedor publicitario.

## 5. Disponibilidad

La aplicación se proporciona tal como esté disponible. Pueden existir cambios, interrupciones o errores durante el desarrollo y las pruebas.

## 6. Cambios

Estas condiciones podrán actualizarse antes de la publicación. La versión vigente deberá revisarse junto con la política de privacidad publicada.

Pendiente de completar con el nombre legal y la dirección de contacto del responsable de la aplicación.

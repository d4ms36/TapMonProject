# Política de Privacidad de TapMon: Mi Compi Virtual

**Última actualización:** 8 de septiembre de 2026

## 1. Información que recopilamos
TapMon no recopila, almacena ni comparte información personal identificable de los usuarios. 

## 2. Datos del dispositivo
La aplicación solo utiliza identificadores anónimos del dispositivo para mostrar anuncios personalizados a través de Google AdMob, según sus propias políticas de privacidad.

## 3. Permisos
- **Internet**: Necesario para cargar anuncios.
- **Almacenamiento**: Solo para guardar el progreso del juego localmente (PlayerPrefs).

## 4. Servicios de terceros
- **Google AdMob**: Para mostrar anuncios. Consulta su política en [https://policies.google.com/privacy](https://policies.google.com/privacy).
